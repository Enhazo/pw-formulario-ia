# Formulário sobre Inteligência Artificial

Exercício escolar em HTML com perguntas sobre conhecimento e uso de ferramentas de inteligência artificial.

## Abrir

Abra `index.html` em um navegador. Os quatro PNGs do projeto devem permanecer junto com o HTML.

## Privacidade e funcionamento

Esta é uma demonstração estática: o formulário não envia nem armazena respostas. A página exibe um aviso para não inserir dados pessoais.

As imagens foram mantidas a partir dos arquivos do projeto escolar; suas licenças/origens externas não foram confirmadas.
